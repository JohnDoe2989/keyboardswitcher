# RU/EN Switcher

Лёгкая утилита для Windows, которая переключает раскладку клавиатуры одиночным нажатием на Ctrl: **левый Ctrl — русский, правый Ctrl — английский**. Никаких «циклических» переключений: каждая клавиша всегда ставит свой язык.

## Возможности

- **Левый Ctrl → RU, правый Ctrl → EN** (одиночный короткий тап, до 300 мс)
- Комбинации вроде `Ctrl+C`, `Ctrl+V`, `Ctrl+Shift+…` работают как обычно и раскладку не меняют
- Иконка в системном трее показывает текущий язык (флаг РФ / флаг США)
- Иконка автоматически синхронизируется с реальной раскладкой активного окна, даже если язык сменили через `Alt+Shift` или `Win+Space`
- Пауза и возобновление через меню трея
- Защита от повторного запуска
- Работает без консольного окна

## Установка

### Готовый exe

Скачай `RU_EN_Switcher.exe` из раздела [Releases](../../releases) и запусти. Python на компьютере не нужен.

Программа запрашивает права администратора. Без них низкоуровневый хук клавиатуры не работает в окнах, запущенных от администратора (диспетчер задач, некоторые установщики и т. д.).

### Запуск из исходников

Требуется Windows 10/11 и Python 3.10+.

```
pip install pystray pillow
python ru_en_switcher.py
```

## Сборка exe

Нужны Windows и Python 3.10+.

```
pip install pyinstaller pystray pillow
python make_icon.py
pyinstaller RU_EN_Switcher.spec
```

Готовый файл появится в `dist\RU_EN_Switcher.exe`.

Параметры сборки (один файл, без консоли, права администратора, иконка) прописаны в `RU_EN_Switcher.spec`. Это эквивалент команды:

```
pyinstaller --onefile --noconsole --uac-admin --icon=icon.ico --name RU_EN_Switcher ru_en_switcher.py
```

## Автозапуск вместе с Windows

Так как программа запускается с правами администратора, из папки «Автозагрузка» она не стартует без окна UAC. Надёжнее создать задачу в Планировщике заданий:

1. Открой **Планировщик заданий** → **Создать задачу**.
2. На вкладке «Общие» включи **Выполнять с наивысшими правами**.
3. На вкладке «Триггеры» добавь **При входе в систему**.
4. На вкладке «Действия» укажи путь к `RU_EN_Switcher.exe`.
5. На вкладке «Условия» сними галку **Запускать только при питании от сети**, если нужен запуск на ноутбуке от батареи.

## Как это работает

- Глобальный низкоуровневый хук клавиатуры (`WH_KEYBOARD_LL`) отслеживает нажатия левого и правого Ctrl.
- Если Ctrl отпущен быстрее чем за 300 мс и между нажатием и отпусканием не нажималась другая клавиша, это считается одиночным тапом.
- Смена раскладки выполняется отправкой сообщения `WM_INPUTLANGCHANGEREQUEST` окну с фокусом из отдельного потока, поэтому хук не тормозит ввод.
- Таймер раз в 400 мс сверяет иконку в трее с реальной раскладкой активного окна.

## Известные ограничения

- Ctrl+клик мышью и Ctrl+колесо мыши хук не видит, поэтому очень быстрый такой жест может сработать как тап.
- Поддерживаются только русская (`ru-RU`) и английская раскладки.
- Антивирусы иногда реагируют на программы с глобальным хуком клавиатуры. Исходный код открыт, при ложном срабатывании добавь exe в исключения.
